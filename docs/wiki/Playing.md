# 遊び方

ZORKERB は原作 Zork I と同じく、英語のコマンドを入力して進めるテキストアドベンチャーです。この文書では、入力の形式、よく使うコマンド、保存と復帰の方法を説明します。

## コマンドの形

コマンドは英語の短い文で入力します。大文字と小文字は区別しません。

| 形 | 例 |
| --- | --- |
| 動詞だけ | `look`、`inventory`、`wait` |
| 動詞と物 | `take lamp`、`open mailbox`、`read leaflet` |
| 動詞と物と前置詞 | `put coins in case`、`attack troll with sword`、`unlock grate with key` |
| 複数の物 | `take all`、`take lamp and sword` |
| 続けて入力 | `open mailbox. take leaflet`、`north then east` |
| 人物への指示 | `tell cyclops to ...` のように相手を指定する |

原作と同じ辞書と構文規則で解釈します。辞書にない語には `I don't know the word "..."` と答えます。語の判定は原作と同じく先頭6文字で行います。

## よく使うコマンド

| コマンド | 意味 |
| --- | --- |
| `look`（`l`） | 周囲を見る |
| `examine 物`（`x` は使えません） | 物を調べる |
| `inventory`（`i`） | 持ち物を見る |
| `north`、`south`、`east`、`west`、`up`、`down`、`ne`、`nw`、`se`、`sw`（`n`、`s` などの略記も可） | 移動する |
| `take 物`、`drop 物` | 拾う、置く |
| `open 物`、`close 物` | 開ける、閉める |
| `turn on lamp` | ランプを点ける |
| `again`（`g`） | 直前のコマンドを繰り返す |
| `oops 語` | 直前の入力の未知語を置き換える |
| `score` | 得点と手数を表示する |
| `verbose`、`brief`、`superbrief` | 部屋の説明の表示量を切り替える |
| `diagnose` | 体の状態を見る |
| `version` | 原作の版情報を表示する |

`x` は原作 Release 119 の辞書にないため、`examine` を使ってください。

## 保存と復帰

| 操作 | 入力 |
| --- | --- |
| 保存 | `save`（スロット0）、`save 3`（スロット3） |
| ゲーム中に復帰 | `restore`、`restore 3` |
| タイトル画面から復帰 | `1` を入力し、続けてスロット番号を入力 |

- 保存に成功すると `Ok.`、失敗すると `Failed.` と表示されます。原作でファイル名を入力する場面を、0〜9のスロット番号で置き換えています。
- スロット番号を付けずに `save` すると、スロット0に上書きします。
- セーブ形式は29です。r28以前の版のセーブ、原作の Quetzal セーブは読み込めません。
- セーブはゲームフォルダー内の `.pyemuera/` に作られます（PyEmuera の仕様）。

## 最初から・終了

| 入力 | 動作 |
| --- | --- |
| `restart` | 確認のあと、最初からやり直す |
| `quit` | 確認のあと、終了する |

死亡したときや勝利したときは、原作と同じく RESTART・RESTORE・QUIT から選びます。

## 乱数

戦闘や盗賊の行動などには乱数を使います。乱数の引き方は原作と同じ順序です。

原作のデバッグ用コマンド `#random 数`（1〜999）を入力すると、Z-machine の予測可能な乱数モードに切り替わります。このモードでは、同じ入力に対して原作と同じ乱数列になります。

## 原作の手引き

原作の遊び方の説明は、ゲーム開始直後に郵便受けの中のリーフレット（`read leaflet`）で読めます。
