# Wiki sources

`docs/wiki/` holds the sources of the ZORKERB wiki in Japanese and English: 20 pages, `_Sidebar.md` and `_Footer.md`. Links between pages use GitHub Wiki page names (for example `Getting-Started`), not repository paths. English pages end in `-English`.

These pages are based on the documents in `docs/`, and the following pages are generated from them:

- Getting-Started, Playing, Saving-and-Restoring
- Compatibility-and-Limitations
- Testing-and-Verification
- Developer-Guide
- Architecture
- the Japanese Original-Source page

When a document in `docs/` changes, update the matching wiki pages in both languages.

Changes here do not update the published wiki. The wiki is a separate Git repository and is updated separately.
