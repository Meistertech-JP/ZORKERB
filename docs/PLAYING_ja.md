# 遊び方

ZORKERB I・ZORKERB II は、原作と同じく英語のコマンドを入力して進めるテキストアドベンチャーです。入力の形式、よく使うコマンド、保存と復帰を説明します。English: [PLAYING_en.md](PLAYING_en.md)

## コマンドの形

コマンドは英語の短い文で入力します。大文字と小文字は区別しません。

| 形 | 例 |
| --- | --- |
| 動詞だけ | `look`、`inventory`、`wait` |
| 動詞と物 | `take lamp`、`open door`、`read leaflet` |
| 動詞と物と前置詞 | `put coins in case`、`attack troll with sword`、`unlock grate with key` |
| 複数の物 | `take all`、`take lamp and sword`、`take all but sword` |
| 続けて入力 | `open mailbox. take leaflet`、`north then east` |
| 人物への指示 | `tell robot to ...` のように相手を指定する |

収録作品は、原作 story と同じ辞書と構文規則で解釈します。辞書にない語には `I don't know the word "..."` と答えます。語の判定は原作と同じく先頭6文字で行います。

## よく使うコマンド

| コマンド | 意味 |
| --- | --- |
| `look`（`l`） | 周囲を見る |
| `examine 物` | 物を調べる（`x` は原作の辞書にないため使えません） |
| `inventory`（`i`） | 持ち物を見る |
| `north`、`south`、`east`、`west`、`up`、`down`、`ne`、`nw`、`se`、`sw`（`n`、`s` などの略記も可） | 移動する |
| `take 物`、`drop 物` | 拾う、置く |
| `open 物`、`close 物` | 開ける、閉める |
| `turn on lamp` | ランプを点ける |
| `again`（`g`） | 直前のコマンドを繰り返す |
| `oops 語` | 直前の入力の未知語を置き換える |
| `score` | 得点と手数を表示する |
| `verbose`、`brief`、`superbrief` | 部屋の説明の表示量を切り替える |
| `diagnose` | 体の状態を見る |
| `version` | 原作の版情報を表示する |

「何を？」と聞かれたときは、物の名前だけを入力して答えられます。

## 保存と復帰

| 操作 | 入力 |
| --- | --- |
| 保存 | `save`（スロット0）、`save 3`（スロット3） |
| ゲーム中に復帰 | `restore`、`restore 3` |
| タイトル画面から復帰 | `1` を入力し、続けてスロット番号を入力 |

- 保存に成功すると `Ok.`、失敗すると `Failed.` と表示されます。原作でファイル名を入力する場面を、0〜9のスロット番号で置き換えています。
- スロット番号を付けずに `save` すると、スロット0に上書きします。
- PyEmuera では、セーブは作品のフォルダー内の `.pyemuera/saves/` に作られます（例：`ZORKERB-I/.pyemuera/saves/`）。セーブは作品ごとに保存されます。
- 壊れたセーブや別のゲームのセーブは読み込みません。ゲーム中なら `Failed.` と表示して状態を変えません。
- 原作の Quetzal 形式のセーブとは互換性がありません。

作品ごとの違いは次のとおりです。

|  | ZORKERB I | ZORKERB II |
| --- | --- | --- |
| 以前の版のセーブ | セーブ形式は29です。r29 のセーブは読み込めます。r28 以前のセーブは読み込みを拒否します | 最初の公開版のため、以前の版はありません |

## 最初から・終了

| 入力 | 動作 |
| --- | --- |
| `restart` | 確認のあと、最初からやり直す |
| `quit` | 確認のあと、終了する |

死亡したときや勝利したときは、原作と同じく RESTART・RESTORE・QUIT から選びます。

## 乱数

戦闘や人物の行動などには乱数を使います。乱数は原作と同じ箇所・同じ順序で引きます。

原作のデバッグ用コマンド `#random 数` を入力すると、Z-machine の予測可能な乱数モードに切り替わり、同じ入力に対して原作と同じ乱数列になります。

|  | ZORKERB I | ZORKERB II |
| --- | --- | --- |
| 使える数 | 1〜999（順次モード） | 1〜999 は順次モード、1000 以上は比較に使った Frotz と同じ生成方法 |

## 原作の手引き

ZORKERB I では、ゲーム開始直後に郵便受けの中のリーフレット（`read leaflet`）で原作の遊び方の説明を読めます。
